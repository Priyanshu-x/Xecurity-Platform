# Xecurity Platform

Xecurity Platform is a robust, full-stack licensing and release management platform. It is designed to track devices via hardware fingerprinting, manage software releases, and issue offline, cryptographically-signed licenses (`.wfalic`) for distributed applications.

## Architecture Overview

The platform consists of a decoupled frontend and backend:

### 1. Frontend (Admin Dashboard)
- **Framework**: Next.js 14+ (App Router), React, TypeScript
- **Styling & UI**: Tailwind CSS, Shadcn UI
- **State Management & Data Fetching**: React Query, Axios
- **Purpose**: Provides a unified administrative interface for managing Organizations, Products, Devices, Releases, and Activation Requests. It features dark-mode tailored UI, complex form wizards (e.g., License Generation), and interactive data tables.

### 2. Backend (API Services)
- **Framework**: Python, FastAPI
- **Database**: PostgreSQL (asyncpg), SQLAlchemy ORM, Alembic migrations
- **Cryptography**: EdDSA (Ed25519) for signing offline license payloads
- **Purpose**: Handles business logic, database transactions, and cryptographic license generation. It exposes a RESTful JSON API (`/api/v1`) for the frontend dashboard and potentially client software to interact with.

## Key Features

1. **Hardware-Bound Licensing**: Parses incoming `.wfareq` files (containing machine fingerprints, OS details, and hardware tokens), reviews them, and generates signed `.wfalic` files bound exclusively to that machine's hardware.
2. **Release Management**: Tracks software versions, build numbers, release channels (STABLE, BETA, etc.), and mandatory update flags. Client applications can query this to determine if they need to auto-update.
3. **Organization & Product Structuring**: Hierarchical management of clients (Organizations) and software suites (Products) allowing multitenant tracking of licenses and deployments.
4. **Offline Validation**: The licenses generated by this platform are designed to be validated entirely offline by the client application (like the WhatsApp Forensic Analyzer) using a hardcoded public key.

## Cryptography & Security

This platform utilizes public-key cryptography to secure the offline licenses. 
- The **Private Key** must be kept strictly confidential on the backend via environment variables (`LICENSE_PRIVATE_KEY`). 
- The client application distributes the corresponding **Public Key** to verify the payload signature (`signature` field) locally without phoning home.
